# Sistema de Catraca - ETEC Zona Leste

Este projeto é um exemplo de PWA (Progressive Web App) para controle de acesso via catraca.

## Estrutura
- `home.html`: Página inicial com informações do sistema.
- `login.html`: Tela de login do usuário.
- `index.html`: Exemplo de tela de login tradicional.
- `css/style.css`: Estilos do sistema.
- `icons/`: Ícones do PWA.
- `model/`: Modelos JS de exemplo.
- `main.js`: Script principal.
- `meuserviceworker.js`: Service Worker para funcionamento offline.
- `manifest.json`: Manifesto PWA.
